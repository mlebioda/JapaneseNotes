# 文法

## 可能形（かのう) - potential form - can

Structure
 - が + V 可能形
	 - 私は日本語の新聞を読みます - i read japanese newspapers
	 - 私は日本語の新聞**が**読**めます** - i can read japanese newspapers

Transforming verbs:
- Group 1:
	- む -> め 
		- 読む -> 読める
	- う -> 買える
	- いる、える from group 1
		- 入る -> 入れる
		- 帰る -> 帰れる
- group 2:
	- る
		- 食べる -> 食べられる
		- 起きる -> 起きられる (お)
	- く
		- 書く -> 書ける、かけません、書けない
- Group 3
	- 来る -> 来られる（こ）
	- する -> できる
	- けっこんする -> けっこんできる

遊ぶ (あそ) - 遊べる
泳ぐ（およ) - 泳げる
立つ - 立てる
入る - 入れる

借りる - 借りられる
教える - 教えられる

じゅんびする - じゅんびできる
くる - こられる

## ....します - situation is changed through a person's will - なる but because of person, not nature

- ...なります - change state because of nature

- ...します - change caused by person
	- エアコンをつけて、部屋を暖かくしましょう - Turn on the air conditioner to make room warm (become warm by human will)

- N+ を。。。します　- when mention an subject to change

## V「なくて」はいけません - must to do something

Comparsion
- Vなければなりません
	- more formal
	- if i don't fo something... something not happen
	- sounds like rule
- Vなくてはいけません - because 
	- more casual

Structure:
- V「なくて」はいけません/いけない - must to do something
	- 海外に行く時は、パスポートを持たなくてはいけません。(かいがい・い・とき・も) - You must take your passport when you go abroad.
- Casual way:
	- V＋なくちゃい(けない )
		- 会議が始まると休めないから、今からランチを食べなくちゃ(いけない) - If meetign begins, I don't have time, so I have to eat lunch not (casual have to)


#w 海外に行く時は、パスポートを持たな**くてはいけません**。(かいがい・い・とき・も) - You must take your passport when you go abroad. (less formal have to)
#w このDVDは金曜日までに返さ**なくてはいけません**。(きんようび・かえ) - I have to return this DVD by Friday.(less formal have to)
#w 日本語会話の練習なので、みなさんは日本語で話さな**くてはいけないよ**。(にほんごかいわ・れんしゅう・にほんご・はな) - It is a Japanese conversation exercise, so everyone must speak Japanese.(less formal have to)

## ように - act on purpose or goal in mind, in order to, so that

Structure:
- V「stem」ように
- V「nai」ように
	- Before ように - goal
	- Often used with potential form 

#w 電車に間に合う**ように**、駅まで走って行きます(でんしゃ、ま、あ、えき、はし) - In order to cat the train, I will run to the station
