# 文法

## 条件形（じょうけんけい）- ば - conditional form

**Structure:** A ば、B — "If A, then B"

### Conjugation
#### Verbs

**Group 1 (U-verbs):** change the final う-sound to the え-row + ば

| Plain | ば form |
| ----- | ------ |
| 書く    | 書けば    |
| 飲む    | 飲めば    |
| 話す    | 話せば    |
| 待つ    | 待てば    |
| 乗る    | 乗れば    |

**Group 2 (RU-verbs):** drop る → add れば

| Plain | ば form |
|-------|---------|
| 食べる | 食べれば |
| 見る | 見れば |

**Group 3 (irregular):**

| Plain | ば form |
|-------|---------|
| する | すれば |
| くる | くれば |

**Negative ば:** ない → なければ
- 食べない → 食べなければ
- しない → しなければ

#### い-adjectives

Drop い → add ければ

| Plain | ば form |
|-------|---------|
| 高い | 高ければ |
| 安い | 安ければ |
| いい | よければ |

#### な-adjectives

Add **であれば** (or なら（ば - often omitted） in casual speech)

| Plain | ば form - formal written | natural, spoken |
| ----- | ----------------------- | --------------- |
| 大切    | 大切であれば                  | 大切なら（ば）         |


#### Nouns

Add **であれば** (or なら（ば - often omitted） in casual speech)

| Plain | ば form - formal written | natural, spoken |
| ----- | ----------------------- | --------------- |
| 学生    | 学生であれば                  | 学生なら（ば）         |
| 日本人   | 日本人であれば                 | 日本人なら（ば）        |
#### Examples
#w このボタンを押(お)せば、ドアが開(ひら)きます。 - If you press this button, the door will open.

#w このケーキがおいしければ、また買(か)いに行(い)きます。 - If this cake is delicious, I will go to buy it again.

#w 非常(ひじょう)に不便(ふべん)じゃなければ、引越(ひっこ)しする必要(ひつよう)がありません。 - If it's not extremely inconvenient, there's no need to move.

#w 明日(あした)いい天気(てんき)なら、一緒(いっしょ)に散歩(さんぽ)に行(

### ば vs たら vs と vs なら — comparison

|                         | ば                          | たら                                    | と                                              | なら                                             |
| ----------------------- | -------------------------- | ------------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| **Formation**           | う→えば / ければ / であれば          | た form → たら                           | dictionary form + と                            | plain form + なら (no conjugation)               |
| **Focus**               | condition (hypothetical)   | when / after / if (sequential)        | natural consequence / always true              | reacts to assumed / stated intention           |
| **Result**              | can be hypothetical        | result always follows after condition | result *always* follows automatically          | advice / suggestion based on what A plans      |
| **Speaker's will in B** | ✅ can express wish/request | ✅ can express wish/request            | ❌ B must be objective fact, not speaker's will | ✅ very common with suggestions                 |
| **Past events**         | ❌                          | ✅ (たら can express discovery: したら〜だった) | ❌                                              | ❌                                              |
| **Nuance**              | logical / formal           | most versatile, everyday use          | automatic / inevitable                         | "since you're going to" / "if that's the case" |


#### Examples with the same meaning

| ば                               | たら                                | と                                        |
| ------------------------------- | --------------------------------- | ---------------------------------------- |
| 春になれば、花が咲く。                     | 春になったら、花が咲く。                      | 春になると、花が咲く。                              |
| If spring comes, flowers bloom. | When spring comes, flowers bloom. | When spring comes, flowers always bloom. |

#### When they are NOT interchangeable

**と — cannot use when B is speaker's will/desire/request:**
- ❌ 駅に着くと、電話してください。
- ✅ 駅に着いたら、電話してください。 — When you arrive at the station, please call.

**たら — discovery (past):**
- 家に帰ったら、誰もいなかった。— When I got home, nobody was there. (ば/と cannot replace this)

**ば — more formal/hypothetical, common in set expressions:**
- よければ — if you'd like
- 行けば良かった — I should have gone

## ために - for (purpose of)

> In Polish: żeby, po to żeby, w celu

|                         | ために                                      | ように                                               |
| ----------------------- | ---------------------------------------- | ------------------------------------------------- |
| **Meaning**             | in order to / for the purpose of         | so that / in hopes that                           |
| **A (condition)**       | volitional verb (you control it)         | non-volitional verb / potential / negative        |
| **B (result)**          | action you directly do                   | state that happens / becomes possible             |
| **Control over result** | ✅ direct                                 | ❌ indirect / not guaranteed                       |
| **Example**             | 勉強するために練習する — practice in order to study | 上手になるように練習する — practice so that I become good     |
| **Negative form**       | ✅ ないために (in order not to)                | ✅ ないように (so that it doesn't happen) — more common |
| **Polish**              | żeby zrobić                              | żeby się stało / żeby było możliwe                |

- V「dict」＋ ために
- N　の ために

### Examples

## V「て-form」くる / きた — action continuing over time

Expresses an action or change that has been building up over a period of time.

Structure:
1. **てきた** — from past up to now (the arrow goes → present)
2. **てくる** — from now continuing into the future

```
past ────────────────●──────────────→ future
                  present
勉強してきた →●  (studied and arrived at now)
                  ●→ 勉強してくる  (will keep studying from now)
```

| Sentence                 | Meaning                                                     |
| ------------------------ | ----------------------------------------------------------- |
| 日本語(にほんご)を勉強(べんきょう)してきた。 | I have been studying Japanese (up to now).                  |
| 日本語を勉強する人(ひと)が増(ふ)えてきた。  | The number of people studying Japanese has been increasing. |

Note: this is **not** physical movement — くる/きた here means the action *accumulated toward the present*. Compare:
- ている — describes a current state or ongoing action (snapshot)
- てきた — emphasizes the action built up *over time* leading to now

### Examples
#w 日本語(にほんご)を勉強(べんきょう)してきた - I have been studying Japanese (up to now).
#w 日本語を勉強する人(ひと)が増(ふ)えてきた - The number of people studying Japanese has been increasing.

## ている → てる / ていた → てた (casual contraction)

In casual spoken Japanese, **ている** and **ていた** are commonly contracted by dropping the い.

| Formal | Casual | Meaning |
|--------|--------|---------|
| 知っている | 知ってる | to know |
| やっている | やってる | to be doing |
| 言っていた | 言ってた | was saying / used to say |
| やっていた | やってた | was doing / used to do |
| 勉強していた | 勉強してた | was studying |

The **よ** particle at the end adds an assertive/informing tone — "you know" or "I'll have you know."

**Example:**
- クラブ活動(かつどう)でやっていたよ。→ やってたよ。
- I used to do it as a club activity (you know).

This contraction is casual speech only — avoid in formal writing or polite situations.
