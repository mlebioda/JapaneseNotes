# 文法

## 。。。はずです - should do/ought (logically)

>Feeling of assurance as a result of some reasonable assumption - He is an English teacher so he should speak english



|Pattern|Form|Meaning|Strength|Source|
|---|---|---|---|---|
|なければなりません|Vない + なければなりません|Must / have to (formal, rule-like)|★★★ strongest|UN5GL10 _(unprocessed)_|
|なくてはいけません|Vない + くてはいけません|Must / have to (casual, personal reason)|★★★|UN4GL3 _(processed)_|
|てはいけません|Vて + はいけません|Must not / forbidden|★★★ (prohibition)|UN4GL3 _(processed)_|
|**はずです**|V dict/た + はずです|Should logically be / expect to (reasoned)|★★ expectation|UN4GL9 _(unprocessed)_|
|ほうがいいです|Vた/Vない + ほうがいいです|Had better / you should (advice)|★★ advice|UN4GL4 _(processed)_|
|必要がある|Vdict + 必要がある|There is a need to|★★★|UN4GL9 _(unprocessed)_|
|なくてもいいです|Vない + なくてもいいです|Don't have to / no need|✗ negative obligation|UN5GL14 _(unprocessed)_|
|てもいいです|Vて + もいいです|It's okay to / you may (permission)|✓ permission|UN5GL7 _(processed)_|
### Structure

Positive:
- **V「dict」 +  はずです**
	-  佐藤(さとう)さんは英語教師(えいごきょうし)なので、英語(えいご)が話(はな)せるはずです。 - Mr. Sato is an English language teacher, so he should be able to speak English.
- **いadj       +   はずです**
	- さっき暖房(だんぼう)をつけたから、部屋(へや)が暖(あたた)かいはずだ。 - I turned on the heater a little while ago, so the room ought to be warm.
- **なadj + な + はずです**
	- 鈴木(すずき)さんの新(あたら)しい家(いえ)は駅(えき)から遠(とお)いので、静(しず)かなはずです。 - Because Mr. Suzuki's new house is far from the station, it should be quiet.
- **N + の   +     はずです**
	- 今日(きょう)は祝日(しゅくじつ)だから、銀行(ぎんこう)は休(やす)みのはずです。 - Because today is a holiday, the bank should be closed.
**Negative**
- for all types - はずがない/はずではありません  instead of はずです
	- 彼（かれ）は出（で）かけたばかりで、こんなに早（はや）く戻（もど）るはずばがない - He just went out. He couldn't come back so quickly


### Examples
#w 彼（かれ）は出（で）かけたばかりで、こんなに早（はや）く戻（もど）るは**ずばがない** - He just went out. He **couldn't** come back so quickly

#w 佐藤(さとう)さんは英語教師(えいごきょうし)なので、英語(えいご)が話(はな)せる**はずです**。 - Mr. Sato is an English language teacher, so he **should be able** to speak English.

#w さっき暖房(だんぼう)をつけたから、部屋(へや)が暖(あたた)かい**はずだ**。 - I turned on the heater a little while ago, so the room **ought to be** warm.

#w 鈴木(すずき)さんの新(あたら)しい家(いえ)は駅(えき)から遠(とお)いので、静(しず)かな**はずです**。 - Because Mr. Suzuki's new house is far from the station, **it should be quiet**.

#w 今日(きょう)は祝日(しゅくじつ)だから、銀行(ぎんこう)は休(やす)みの**はずです**。 - Because today is a holiday, the bank **should be closed**.

## 通りに。。。（と）- exactly as, as, just like

> To indicate doing something as planned or instructed

### Structure
- V「た」 通りに。。。（と）
	- わたしが書(か)いたとおりに、書(か)いてください。 - Please write exactly as I have written.
- N の　　通りに。。。（と）
	- 予定(よてい)のとおり、9時(じ)に集合(しゅうごう)します。 - As planned, we will gather at 9 o'clock.
- N 　　　通りに。。。（ど）- without の sound is changing
	- 予定(よてい)どおり、9時(じ)に集合(しゅうごう)します。 - As planned, we will gather at 9 o'clock.
- As noun can be used:
	- このとおり - like this / in this way
	- そのとおり - exactly / that's right / like that
	- あのとおり - like that (over there) / as you can see
		- このとおりに、やってください。 - Please do it exactly like this.

### Examples

#w 通り（と）に - exactly as, as, just like

#w わたしが書(か)い**たとおりに**、書(か)いてください。 - Please write exactly as I have written.

#w 「**予定(よてい)どおり/予定(よてい)のとおり**」、9時(じ)に集合(しゅうごう)します。 - As planned, we will gather at 9 o'clock.  (2 readings)

#w 昨日(きのう)のサッカーの試合(しあい)は、思(おも)**ったとおりに**、山田(やまだ)さんのチームが勝(か)った。 - As I thought, Mr. Yamada's team won the soccer game yesterday.

#w 先生(せんせい)が言(い)っ**たとおりに**、勉強(べんきょう)しました。 - I studied as the teacher said.

#w 約束(やくそく)「**のとおり・どおり**」に、9時(じ)に駅(えき)に来(き)ました。 - I came to the station at 9:00 as promised.

#w **このとおりに**、やってください。 - Please do it exactly **like this**.

### Use cases

#### Used as noun - there is (not) need

##### Structure
- V「dict」- 必要（ひつよう）がある
	- 明日（あした）は休（やす）みだが、学校（がっこう）に行（い）く必要（ひつよう）がある - Tomorrow is a day off, but there is need to go to school
- V「dict」- 必要（ひつよう）がない
	- あの子(こ)におもちゃを買(か)ってあげたから、新(あたら)しいおもちゃを買(か)う必要(ひつよう)がない。 - Since I bought that child a toy, there is no need to buy a new toy.

##### Examples

 #w 明日（あした）は休（やす）みだが、学校（がっこう）に行（い）く**必要**（ひつよう）がある - Tomorrow is a day off, but **there is need** to go to school
 
#w あの子(こ)におもちゃを買(か)ってあげたから、新(あたら)しいおもちゃを買(か)う必要(**ひつよう)がない。 - Since I bought that child a toy, there is no need to buy a new toy.
