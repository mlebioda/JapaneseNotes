
## Powtórzenie
- ている　- też coś zaczęło się w przeszłości i trwa do teraz,
- なる-  stać się
	- いprzymiotniki　く
		- Oい　-> Oくなる - forma twierdząca
			- あつい -> あつくなる
		- Oない　→　Oなくない - forma przecząca
			- あつくなく  -> あつくなくなる 
	- なprzymiotniki　に
		- Oに ->　Oになる - forma twierdząca
			-　しずかに　→　しずかになる
		- Oじゃない→　Oじゃなくなる - forma przecząca
			- しずかじゃない　→　しずかじゃなくなる
	- 　rzeczowniki に
		- OO＋に＋なる - jeśli stało się coś wg naszej woli i niezależnie
			- いしゃ　→　いしゃになる - stałem się lekarzem
			- はるに　→　はるになる - stała się wiosna
	- czasowniki w formie przeczącej
		- OOOない　→　OOOなくなる
			- 行かない　→　行かなくなる - stało się, że nie poszedłem,
- Porównanie のほうが(bardziej)～より(niż/od)
	- AよりB - A  niż B - Tam gdzie のほうが  ta jest bardziej
		- 1 sposób
			- AのほうがBよりO - A jest bardziej O niż B
				- 日本のほうがポーランドより大きいです - Japonia jest większa od Polski
		- 2 sposób 
			- A より B のほうがOです - B jest bardziej O od A
				- 昨日 より 今日のほうが 暑いです - dzisiaj jest cieplej niż wczoraj
		- w odpowiedzieć w skrócony sposób バスのほうがたかいです
		- odpowiedź - 1 wybór
			- なつ のほうが ふゆ より 好きです
			- なつ　のほうが　好きです -  z pominięciem より
		- odpowiedź - wybór 2 rzeczy
			- なつ　も　ふゆ　も　好き/きらい　です,
	- XとYとどっち／どれのほうがZですか - X czy Y, które jest bardziej Z?
		- 電車とバスとどちらのほうがはやいですか - pociąg czy autobus, które jest szybsze,
		- Pytania:
			- なつ　と　ふゆ　と　どちら　のほうが好きですか
			- なつ　と　ふゆ　と　どちら　が好きですか - Z pominięciem のほう
-  の中で - porównywanie więcej niż 2 rzeczy
	- XとYとZ  の中で、Oが一番Vですか
		- X, Y, Z
		- Pytajnik - O 
			- どれ - który (which one)
			- だれ -  kto
			- どこ - gdzie
			- いつ - kiedy
		- V - przymiotnik
	- ロシアとフランスと日本の中で、どこが一番さむいですか？
		- ロシアが一番さむい,
- ~ね - oznaka, że się zwraca do kogoś, a nie stwierdza fakt,
- chcieć - Czasowniki
	- 1 osoba
		- Xます -> たい (desu - jeśli grzeczniej) 
			- たべます -> たべたい
			- のみます ->　のみたい
			- します　-> したい
		- Nie chcieć
			- Oたい -> Oたくない - forma bezpośrednia
			- Oたい -> Oたくないです - forma grzeczniejsza
			- Oたい -> あまりOたくないです - forma grzeczniejsza (nie za bardzo chcę),
		- Chcieć - czas przeszły
			- たい -> たかった 
				- 行きたい -> 行きたかった
				- したかった - chciałem zrobić
			- przeszły przeczący
				- たい -> たかった -> たくなかった
					- あそびたい -> あそびたくない - あそびたくなかった
	- Chcieć - 3 osoba
		- Dla wszystkich form jak dla 1 osoby + といっていました
		- た**がっている** - 2 sposób "wygląda na to" wynika to z tego, że nie mogą być pewni co 2 osoba myśli więc nie można użyć formy たい
			- **Xます　->　Xたがっている**
				- たべますー＞たべたがっている
				- メアリーさんはきものを 着たがっています（き）- Meari chce założyć kimono
- Chcieć - rzeczownik
	- 1 Osoba
		- Twierdzenie  ～がほしい(です)　－**chcę** (o rzeczownikach)
			- 漢字 の じしょ **が ほしい**です (かんじ) - chcę słownik kanji
		- Przeczenie ~がほし**くない**(です) - nie chcę (o rzeczownikach)
			- 漢字 の じしょ **が ほしいくない**です (かんじ) - nie chcę słownika kanji
	- 3 Osoba
		- ほし(い/くない）と言っていました(と) - Forma cytatu
		- **を** + ほし**がる**/ほし**がっています** - zmiana partykuły!!!!!!!!!!
			- ロバートさんはパソコン**を ほしがっています**,
- 日本 - にほん vs にっぽん 
	- にっぽん - nazwa własna
		- bank japoni
		- gambare nippon,
- ありがとう　ございました - grzeczniejsze, albo za coś co już było,
- こちら vs この - kochira more polite - shop staff to customer,
- さいきん＋forma prosta czasownika + 時間がありません  (brak partykuły) - ostatnio nie mam czasu na...,
- wydaje się (przymiotniki)
	- い　przymiotniki
		- からい - からそう - wydaje się ostry
	- な przymiotniki
		- しずかそう - wydaje się spokojny,
