**Why**: The newly added Calendar sync feature contained critical ICS correctness bugs (zero-duration all-day events silently dropped by Apple Calendar; missing RFC 5545 line folding causing import failures in strict clients), a hardcoded session mount path that would break across sessions, and fragile date string handling. A user design decision also switched from single-file overwrite to timestamped files per session.
**Lesson**: **[Rule]** For ICS all-day events, DTEND must be the exclusive next day (DTSTART + 1 day per RFC 5545 §3.6.1) — a DTEND equal to DTSTART produces a zero-duration event that Apple Calendar silently discards.
