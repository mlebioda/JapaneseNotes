# Transitive and Intransitive verbs

> Whether a verb takes a direct object (transitive, 他動詞) or not (intransitive, 自動詞), reflected in which particle attaches to it.

## Structure

| Intransitive (自動詞)         | Transitive (他動詞)                  |
| -------------------------- | --------------------------------- |
| 起きる（おきる） - to wake up      | 起こす（おこす） - to wake (someone) up   |
| 倒れる（たおれる） - to fall        | 倒す（たおす） - to knock down           |
| 壊れる（こわれる） - to be broken   | 壊す（こわす） - to break                |
| 返る（かえる） - to go back / be returned | 返す（かえす） - to return (something)  |
| 割れる（われる） - to break/crack (on its own) | 割る（わる） - to break (something) |
| 決まる（きまる） - to be decided   | 決める（きめる） - to decide              |
| 開く（あく） - to open (by itself) | 開ける（あける） - to open (something)  |
| 付く（つく） - to be attached    | 付ける（つける） - to attach / to turn on |
| 始まる（はじまる） - to begin (on its own) | 始める（はじめる） - to begin (something) |
| 増える（ふえる） - to be increased | 増やす（ふやす） - to increase            |
| 焼ける（やける） - to be burnt     | 焼く（やく） - to grill                 |
| 消える（きえる） - to disappear     | 消す（けす） - to turn off / erase       |
| 直る（なおる） - to be fixed       | 直す（なおす） - to fix                  |
| 治る（なおる） - to recover / heal | 治す（なおす） - to cure                 |
| 回る（まわる） - to turn (on its own) | 回す（まわす） - to turn (something)  |
| 冷える（ひえる） - to cool down     | 冷やす（ひやす） - to cool               |
| 濡れる（ぬれる） - to get wet       | 濡らす（ぬらす） - to wet                |
| 沸く（わく） - to be boiled        | 沸かす（わかす） - to boil               |
| 止まる（とまる） - to stop (on its own) | 止める（とめる） - to stop (something) |

- Transitive: Object を + Verb → ドアを開ける（あ） - To open the door.
- Intransitive: Object が + Verb → ドアが開く（あ） - The door opens
- Intransitive: Object に + Verb (direction/target) → 東京（とうきょう）に行く（い） - to go to Tokyo
- Intransitive: Object へ + Verb (direction) → 学校（がっこう）へ行く（い） - to go to school
- Intransitive: Object と + Verb (companion) → 友達（ともだち）と話す（はな） - to talk with a friend

## Examples

- ドアを開(あ)ける - To open the door.
- ドアが開(あ)く - The door opens

## Notes

A rough (not exceptionless) mnemonic: transitive verbs often end in -eru/-asu/-osu, while their intransitive partners often end in -aru/-eru — compare 閉める(しめる, transitive)/閉まる(しまる, intransitive) or the pairs in the table above.

## Register

Register: neutral
Transitivity is a lexical property of the verb pair itself, not a politeness marker — either member of a pair can be conjugated in polite (ます) or plain form depending on context.
