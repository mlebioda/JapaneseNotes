# Months 月

> Names of the months, and counting a duration in months.

## 1. Month names

### Structure

| Month | Reading | Meaning |
|---|---|---|
| 一月 | いちがつ | January |
| 二月 | にがつ | February |
| 三月 | さんがつ | March |
| 四月 | しがつ | April (irregular) |
| 五月 | ごがつ | May |
| 六月 | ろくがつ | June |
| 七月 | しちがつ | July (irregular) |
| 八月 | はちがつ | August |
| 九月 | くがつ | September (irregular) |
| 十月 | じゅうがつ | October |
| 十一月 | じゅういちがつ | November |
| 十二月 | じゅうにがつ | December |
| 何月 | なんがつ | what month? |

## 2. Counting months

### Structure

Number + か月（間）(間 optional)

| Number | Reading | Meaning |
|---|---|---|
| 一か月(間) | いっかげつかん | 1 month |
| 二か月(間) | にかげつかん | 2 months |
| 三か月(間) | さんかげつかん | 3 months |
| 四か月(間) | よんかげつかん | 4 months |
| 五か月(間) | ごかげつかん | 5 months |
| 六か月(間) | ろっかげつかん | 6 months |
| 七か月(間) | ななかげつかん | 7 months |
| 八か月(間) | はちかげつかん | 8 months |
| 九か月(間) | きゅうかげつかん | 9 months |
| 十か月(間) | じゅっかげつかん | 10 months |
| 十二か月（かん) | じゅうにかげつ | 12 months |

## Use Cases

か月 is also written ヶ月 (same reading) — an orthographic variant only, with no difference in register.

## Register
Register: neutral
Month names and the か月 counter attach the same way regardless of formality — used identically in casual conversation and polite/formal speech.
