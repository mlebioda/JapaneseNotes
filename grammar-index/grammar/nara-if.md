# 。。。なら。。。- if

> "Since you're doing A anyway" / "if that's the case" — reacts to an already-stated or assumed premise (A), then states the speaker's own will, advice, or suggestion (B).

## Structure

### Verb

- Present: V「dict」+ なら → 買うなら - if you're going to buy

### い-adjective

- Present: Adj + なら → 近いなら - if it's near

### な-adjective

- Present: Adj + なら (no だ) → 嫌いなら - if you don't like it

### Noun

- Present: N + なら (no だ) → 彼なら - if it's him

**Common mistake:** nouns and な-adjectives attach directly to なら with no だ — 彼なら, not ~~彼だなら~~; 嫌いなら, not ~~嫌いだなら~~.

## Examples

- 手袋(てぶくろ)を買(か)うなら、駅前(えきまえ)の店(みせ)がいいと思(おも)います。 - If you're going to buy gloves, I think the store around the station is good.
- 近(ちか)いなら、歩(ある)いて行(い)きます。 - If it is near, I will walk.
- 嫌(きら)いなら、もう食(た)べなくてもいいよ。 - If you don't like it, you don't have to eat it any more.
- 彼(かれ)なら、きっとできると思(おも)う。 - If it is him, I think he can surely do it. (topic-marking use: "as for him / speaking of him" — reacting to 彼 as the topic under discussion)

## Use Cases

A is the condition (something already planned, stated, or assumed); B is the speaker's own will — a reaction, piece of advice, or suggestion given that premise. Register: neutral — used freely in both casual and polite speech, with no separate formal variant (unlike ば's であれば).

## Notes

**ば vs たら vs と vs なら — comparison:**

|                         | ば                          | たら                                    | と                                              | なら                                             |
| ----------------------- | -------------------------- | ------------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| **Formation**           | う→えば / ければ / であれば          | た form → たら                           | dictionary form + と                            | plain form + なら (no conjugation)               |
| **Focus**               | condition (hypothetical)   | when / after / if (sequential)        | natural consequence / always true              | reacts to assumed / stated intention           |
| **Result**              | can be hypothetical        | result always follows after condition | result *always* follows automatically          | advice / suggestion based on what A plans      |
| **Speaker's will in B** | ✅ can express wish/request | ✅ can express wish/request            | ❌ B must be objective fact, not speaker's will | ✅ very common with suggestions                 |
| **Past events**         | ❌                          | ✅ (たら can express discovery: したら〜だった) | ❌                                              | ❌                                              |
| **Nuance**              | logical / formal           | most versatile, everyday use          | automatic / inevitable                         | "since you're going to" / "if that's the case" |

## Register

Register: neutral
なら is used freely across casual and polite speech with no separate formal variant, unlike ば (which has であれば for formal/written contexts) — the surrounding verb/adjective politeness (plain vs ます/です) carries the formality instead.

## Often confused with

- [条件形（じょうけんけい）- ば - conditional form](/JapaneseNotes/grammar-index/grammar/joukenkei-ba-conditional-form) — test: does B react to an already-stated/assumed plan (なら) or express a general hypothetical/logical condition (ば)?
- [。。。場合は, 。。。 - in case of, if](/JapaneseNotes/grammar-index/grammar/baai-in-case-of-if) — test: is this reacting to an already-mentioned plan or premise (なら) or framing a general contingency scenario (場合は)?
- [Interrogative V conditional form + 　いいですか - ask for opinion or advice](/JapaneseNotes/grammar-index/grammar/v-ba-iidesuka) — test: is this an open interrogative "what should I do" advice question (ば/たら, なら doesn't fit) or a reaction to an already-assumed plan (なら)?
- [past tense + たら - if](/JapaneseNotes/grammar-index/grammar/past-tense-tara-if) — test: Does the condition happen before the result (たら), or is the speaker reacting to something already mentioned/known (なら)?
