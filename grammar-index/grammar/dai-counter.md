# 台(だい) - urządzenia mechaniczne, elektroniczne, pojazdy

> The counter 台 (だい), used for machines, electronic devices, and vehicles

## Structure

| Number | Reading | Meaning |
|---|---|---|
| 1台 | いちだい | one machine/device/vehicle |
| 2台 | にだい | two machines/devices/vehicles |
| 3台 | さんだい | three machines/devices/vehicles |
| 4台 | よんだい | four machines/devices/vehicles |
| 5台 | ごだい | five machines/devices/vehicles |
| 6台 | ろくだい | six machines/devices/vehicles |
| 7台 | ななだい | seven machines/devices/vehicles |
| 8台 | はちだい | eight machines/devices/vehicles |
| 9台 | きゅうだい | nine machines/devices/vehicles |
| 10台 | じゅうだい | ten machines/devices/vehicles |
| 14台 | じゅうよんだい | fourteen machines/devices/vehicles |
| 70台 | ななじゅうだい | seventy machines/devices/vehicles |
| 何台 | なんだい | how many machines/devices/vehicles? |

## Examples

- 車（くるま）が２台（にだい）あります。- There are two cars.

## Register
Register: neutral
台 is a plain counter word with no politeness association — used identically in casual conversation, business speech, and writing.
