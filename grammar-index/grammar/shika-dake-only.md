# しか、だけ - only

> Both mean "only", but しか requires a negative verb while だけ requires an affirmative verb.

## Structure

- Noun + しか + negative form - only (nothing but) → 私（わたし）は日本語（にほんご）**しか** 話せない（はな）です - I can speak only Japanese
- Noun + だけ + affirmative form - only → 私（わたし）は日本語（にほんご）**だけ** 話せます（はな） - I can speak only Japanese

## Examples

- 私(わたし)は日本語(にほんご)**しか** 話(はな)せないです - I can speak only Japanese
- 私(わたし)は日本語(にほんご)**だけ** 話(はな)せます - I can speak only Japanese
- 待(ま)つしかない。 - I can only wait.
- この仕事(しごと)は山田(やまだ)さん**しか**できないです。 - Only Mr. Yamada can do this work.
- 冷蔵庫(れいぞうこ)にリンゴは一(ひと)つ**しか**ない。 - There is only one apple in the refrigerator.

## Use Cases

しか also replaces other particles like を/が rather than combining with them — テレビ**しか**見ない, not テレビ**を**しか見ない.

## Register

Register: neutral
Both particles are register-neutral; formality comes entirely from the verb ending they attach to (話せないです is polite, 話せない is plain).

## Often confused with

- [N＋たけ - only N](/JapaneseNotes/grammar-index/grammar/ntake-only-n) — test: Does the sentence use a negative verb (only しか works — 一人しかいません) or an affirmative verb (only だけ works — 一人だけいます)?
