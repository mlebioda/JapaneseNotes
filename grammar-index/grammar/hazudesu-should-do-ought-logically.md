# 。。。はずです - should do/ought (logically)

> Feeling of assurance as a result of some reasonable assumption — states the speaker's confident logical expectation about a state of affairs.

## 1. Positive — logical expectation

### Structure

### Verb
- Present: V「dict」+ はずです → 佐藤(さとう)さんは英語教師(えいごきょうし)なので、英語(えいご)が話(はな)せるはずです。 - Mr. Sato is an English language teacher, so he should be able to speak English. (話せる is itself the dictionary form of the potential verb — はずです just attaches to whatever the final plain form is, including potential/passive/causative conjugations)
- Past: V「た」+ はずです (past event — "should have already ~") → 田中(たなか)さんはもう出発(しゅっぱつ)したはずです。 - Mr. Tanaka should have already left.

### い-adjective
- Present: Adj + はずです → さっき暖房(だんぼう)をつけたから、部屋(へや)が暖(あたた)かいはずだ。 - I turned on the heater a little while ago, so the room ought to be warm.

### な-adjective
- Present: Adj + な + はずです → 鈴木(すずき)さんの新(あたら)しい家(いえ)は駅(えき)から遠(とお)いので、静(しず)かなはずです。 - Because Mr. Suzuki's new house is far from the station, it should be quiet.

### Noun
- Present: N + の + はずです → 今日(きょう)は祝日(しゅくじつ)だから、銀行(ぎんこう)は休(やす)みのはずです。 - Because today is a holiday, the bank should be closed.

### Examples

- 佐藤(さとう)さんは英語教師(えいごきょうし)なので、英語(えいご)が話(はな)せるはずです。 - Mr. Sato is an English language teacher, so he should be able to speak English.
- 田中(たなか)さんはもう出発(しゅっぱつ)したはずです。 - Mr. Tanaka should have already left.
- さっき暖房(だんぼう)をつけたから、部屋(へや)が暖(あたた)かいはずだ。 - I turned on the heater a little while ago, so the room ought to be warm.
- 鈴木(すずき)さんの新(あたら)しい家(いえ)は駅(えき)から遠(とお)いので、静(しず)かなはずです。 - Because Mr. Suzuki's new house is far from the station, it should be quiet.
- 今日(きょう)は祝日(しゅくじつ)だから、銀行(ぎんこう)は休(やす)みのはずです。 - Because today is a holiday, the bank should be closed.

## 2. Negative — はずがない vs はずではない

### Structure

For all word types, use はずがない／はずではありません instead of はずです — but these two aren't simple interchangeable synonyms:
- **はずがない** = "there's no way / it's impossible" — a strong logical negation (はずはない is an interchangeable variant, with no meaningful difference in meaning)
- **はずではない／はずではありません** = "it wasn't supposed to be the case" — contrary to an earlier expectation or plan (softer, about a broken assumption, not logical impossibility)

### Examples

- 彼（かれ）は出（で）かけたばかりで、こんなに早（はや）く戻（もど）るはずがない - He just went out. He couldn't come back so quickly (impossible)
- こんなに難（むずか）しいテストになるはずではなかった。 - This test wasn't supposed to be this hard. (contrary to expectation)

## 3. Related — はずだった (past expectation)

### Structure

はずだった is the past tense of the positive form, not a negative pattern — but it's easy to confuse with はずではなかった because both often describe something that didn't pan out as expected:
- **はずだった** = "was supposed to / should have" — states the past expectation itself, usually implying it wasn't fulfilled
- **はずではなかった** = negates the expectation itself — "it wasn't supposed to be this way" (something unexpected happened)

### Examples

- 彼（かれ）は来（く）るはずだった。 - He was supposed to come. (implying he didn't)

## Notes

Register: neutral — です is the polite form; the plain-form equivalent is はずだ (see い-adjective row in use case 1); no further politeness tiers.

はずです is epistemic, not deontic: unlike must/have-to/advice/permission patterns that tell someone what to do or is allowed to do, はずです states the speaker's confident logical expectation about a state of affairs ("X should logically be true"). Don't read it as "a softer should."

## Register

Register: neutral
です is the standard polite copula; the plain-form equivalent はずだ is used identically in casual speech, with no change to the attachment rules above. Formality is compositional, not fixed to the pattern itself.

## Often confused with

- [...ようです](/JapaneseNotes/grammar-index/grammar/you-desu) — test: Is the speaker deducing from known facts/reasoning (はずです) or judging from what they can see/sense (ようです)?
- [なくてはなりません・なければなりません - must, have to](/JapaneseNotes/grammar-index/grammar/nakutehanarimasen-nakerebanarimasen-must-have-to) — test: Is this a rule/obligation the subject must follow (なければならない) or the speaker's confident logical expectation about a fact (はずです)?
