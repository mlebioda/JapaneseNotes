# から - because

> Attaches a reason to a clause — used either mid-sentence with the result stated explicitly, or sentence-final with the result left implied.

## 1. Mid-sentence — P1から、P2

### Structure

- P1....から.... P2 - "Because P1, P2" (から attaches to the reason clause P1; the result P2 follows) → きょうは早く帰りますから、いっしょに映画を見ましょう（はや、かえ、えいが、み） - because I will come back early today, let's watch a movie together

English translation order is flexible — the same sentence can also be rendered "Let's watch a movie together because I will return early today."

### Examples

- きょうは早(はや)く帰(かえ)りますから、いっしょに映画(えいが)を見(み)ましょう - because I will come back early today, let's watch a movie together
- 天気(てんき)がいいですから、散歩(さんぽ)しましょう - because it is nice weather, let's go for a walk
- 明日早く起きますから、今晩早く寝ます（あした、はや、お、こんばん、はや、ね） - because I will get up early tomorrow, I will sleep early tonight

## 2. Sentence-final — elliptical から

### Structure

- ...., .... から → ここは有名ですから

Typically answers a "why/how" question, with the result left implied by context rather than stated.

### Examples

- A: 新しい家はどうですか B: とてもべんりです。駅に近いですから - A: How is the new house? B: It's very convenient, because it's close to the station
- A: このレストランにたくさんの人がいますね B: ここは有名ですからね (ゆうめい) - A: There are a lot of people in this restaurant, aren't there? B: Because this place is famous, you know

## Register
Register: neutral
から attaches to either plain or ます/です forms and is used across all politeness levels, in either position.

## Often confused with

- [。。。ので - because](/JapaneseNotes/grammar-index/grammar/node-because) — test: Is this a direct/subjective reason the speaker could state standing alone (→ から), or a softer, more objective-sounding reason (→ ので)?
