# Hour

> Stating the hour, optionally with a time-of-day marker.

## Structure

(午前・午後・朝・夜) + Number + 時 + Number + 分

| Number | Reading | Meaning |
|---|---|---|
| 一時 | いちじ | 1 o'clock |
| 二時 | にじ | 2 o'clock |
| 三時 | さんじ | 3 o'clock |
| 四時 | よじ | 4 o'clock (irregular) |
| 五時 | ごじ | 5 o'clock |
| 六時 | ろくじ | 6 o'clock |
| 七時 | しちじ | 7 o'clock (irregular) |
| 八時 | はちじ | 8 o'clock |
| 九時 | くじ | 9 o'clock (irregular) |
| 十時 | じゅうじ | 10 o'clock |
| 十一時 | じゅういちじ | 11 o'clock |
| 十二時 | じゅうにじ | 12 o'clock |

## Examples

## Register
Register: neutral
Hour readings attach the same way regardless of formality — used identically in casual conversation and polite/formal speech.
