# これ/それ/あれ　どれ

> Demonstrative pronouns that stand alone to refer to things by proximity — this, that, that over there, which one.

## Structure

- これ — this (close to speaker) → これは何ですか？ — What is this?
- それ — that (close to listener) → それは本です。 — That is a book.
- あれ — that over there (far from both) → あれは何ですか？ — What is that over there?
- どれ — which one? → どれがいいですか？ — Which one is good?

Unlike この/その/あの/どの, these words replace the noun entirely.
