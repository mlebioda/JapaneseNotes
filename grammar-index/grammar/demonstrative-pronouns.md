# これ/それ/あれ　どれ

> Demonstrative pronouns — stand alone to refer to things by proximity, without a following noun.

## Structure

これ / それ / あれ / どれ (standalone)

- これ — this (close to speaker)
- それ — that (close to listener)
- あれ — that (far from both)
- どれ — which one?

## Examples

- これは何ですか — What is this?
- あれは私の傘です — That (over there) is my umbrella.

## Notes

Part of the こそあど system: こ = near speaker, そ = near listener, あ = far from both, ど = question word. These stand alone without a following noun; see the pre-noun adjective equivalents in See also.
