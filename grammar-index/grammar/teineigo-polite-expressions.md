# 丁寧語（ていねいご) - Polite expressions

> Neutral polite register showing formality and social distance — not tied to relative rank between speaker and listener (that's the job of sonkeigo/kenjougo)

## Structure

| Form      | Function                                    |
| --------- | -------------------------------------------- |
| ます       | Polite verb ending                           |
| です       | Polite copula                                |
| ございます  | More formal version of あります (not います — that becomes おります／いらっしゃいます) |
| でございます | Very formal version of です (e.g. こちらでございます) |
| ましょう    | Polite volitional — "let's / shall we"        |
| でしょう    | Polite presumptive — "probably"               |

Connecting sentences:

| Form | Function                                                 |
| ---- | -------------------------------------------------------- |
| まして  | Polite て-form connector (ます + て), links clauses formally |
| ますので | Polite causal "because," more formal than plain形 + から    |

## Examples

昨日(きのう)部長(ぶちょう)にお礼(れい)を言われまして、とてもうれしかったです。 - I was thanked by the department manager yesterday, and I was very glad.
大事(だいじ)な仕事(しごと)を担当(たんとう)させてもらっていますので、頑張(がんば)らなければなりません。 - I was put in charge of an important job, so I have to try my best.
彼(かれ)は野球(やきゅう)のボールを投(な)げました。 - He threw a baseball.

## Use Cases

Used with strangers, in formal/public settings, or generally to keep polite distance, regardless of whether the listener outranks you, is your equal, or ranks below you.

## Register
Register: tiered (standard polite ます／です; formal ございます／でございます)
The baseline polite register used with strangers and in public or formal settings; the ございます tier appears in customer service, announcements, and very formal speech.
