# **3. お + V「ます形」になります**

> Mid-level sonkeigo pattern: お + verb ます-stem + になります, used when no special verb exists

## Structure

- お ＋ --ます形-- + なります
    - お帰りになります
    - お出かけになります
    - お読みになります
    - お書きになります

## Examples

店長(てんちょう)はいつお帰(かえ)りになりますか - When will the store manager come back?
お出(で)かけになりますか - Will you go out? Czy Pan wychodzi?
何かお聞(き)きになりたいことはありますか - Do you have something to ask? / Czy chcialby pan o cos zapytac?

## Notes

Exceptions:
1. する and 来る (irregular verbs) — never take this pattern; use their own special verbs instead (なさる／いらっしゃる).
2. Ichidan (Group 2) verbs whose ます-stem is only one mora/syllable long:
    - 見る -> み (1 mora) -> use ご覧になる instead of ×おみになる
    - 着る -> き (1 mora) -> use お召しになる instead of ×おきになる
3. Any verb that already has a dedicated special respectful verb — use that instead of this pattern.

## Register
Register: polite-context typical
Mid-tier sonkeigo — used toward superiors and customers when no dedicated special verb exists for the action; more formal than られる but below the special-verb forms.

## Often confused with
- [お・ご V『ます形」します](/JapaneseNotes/grammar-index/grammar/o-go-v-masushimasu) — test: Raising the listener's/a superior's action (→ お＋ます形＋になります), or humbly describing your own action done for them (→ お・ご V「ます形」します)?
- [**2. 特別な動詞（とくべつなどうし）- special verbs**](/JapaneseNotes/grammar-index/grammar/tokubetsunadoushi-special-verbs) — test: No special verb exists for this action (→ お＋ます形＋になる), or one does (→ use the special verb)?
- [1. **動詞(どうし)の尊敬形(そんけいけい) - respectful forms of verbs**](/JapaneseNotes/grammar-index/grammar/sonkeikei-passive-form) — test: More careful respect toward a superior/customer (→ お＋ます形＋になる), or quick/casual respect (→ the られる passive-form pattern)?
