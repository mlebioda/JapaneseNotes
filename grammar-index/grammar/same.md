# 同じ - same

> Pre-noun modifier meaning "same" — placed directly before a noun without any particle.

## Structure

同じ（おなじ）+ Noun → same [Noun]

## Examples

- 同(おな)じ会社(かいしゃ) — same company
- 同(おな)じ大学(だいがく) — same university

## Notes

同じ is a 連体詞 (pre-noun determiner) — it never conjugates. Unlike い-adjectives, there is no ない, かった, or くない form.
