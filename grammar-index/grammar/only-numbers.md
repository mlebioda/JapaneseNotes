# Only numbers

> The core Japanese number system from 0 to 万, including composition rules and irregular readings.

## Structure

- **0–10**: base numbers (れい、いち、に、さん、よん/し、ご、ろく、なな/しち、はち、きゅう/く、じゅう)
- **11–19**: 十 + number (e.g. 十一 じゅういち)
- **20–99**: number + 十 + number (e.g. 二十二 にじゅうに)
- **100–999**: number + 百 + number — note irregular readings: さんびゃく (300)、ろっぴゃく (600)、はっぴゃく (800)
- **1000–9999**: number + 千 + number — note irregular readings: さんぜん (3000)、はっせん (8000)
- **10,000+**: number + 万 (e.g. 一万 いちまん)

## Examples

- 十五 (じゅうご) - 15
- 二十二 (にじゅうに) - 22
- 三百五十三 (さんびゃくごじゅうさん) - 353
- 百十一 (ひゃくじゅういち) - 111
