# Time

> Telling time in Japanese: optionally specify AM/PM or time of day, then hours (時) and minutes (分).

## Structure

- 午前／午後／朝／夜 + Number + 時（じ）+ Number + 分（ぷん／ふん）
- 午前（ごぜん）— AM; 午後（ごご）— PM

## Examples

- 午前九時（ごぜんくじ）— 9:00 AM
- 午後三時三十分（ごごさんじさんじゅっぷん）— 3:30 PM
