# V「て形」＋おきます - V continues without any changes, leave

> Leave something as it is with no changes, or do something in advance as preparation.

## Structure

### Verb

- Present: V「て形」＋おきます → 窓(まど)を開(あ)け**ておいて**ください。 - Please leave the window open.
- Negative: V「て形」＋おかない → あのレストランはとても人気(にんき)ですから、予約(よやく)して**おかないと**入(はい)れません。 - Because that restaurant is very popular, if we don't make a reservation in advance, we can't enter.

V continues without any changes, often with そのまま／このまま — or the action is done in advance as preparation to achieve a goal. Casual spoken contractions: おいておく → おいとく; しておく → しとく.

## Examples

- そのまま にして **おいて** ください - Please leave it as it is
- 窓(まど)を開(あ)け**ておいて**ください。 - Please leave the window open.
- 電気(でんき)はそのままつけ**ておいて**ください。 - Please leave the light on as it is.
- A:　この書類(しょるい)はどこ**におきますか**。B:机(つくえ)の上(うえ)においといて （置いておいてください） - A: Where can I put this file? B: Leave it on the desk
- おいといて （置いておいてください） - leave it as it is, please (short and long version)
- 母(はは)が戻(もど)る前(まえ)に、部屋(へや)を片付(かたづ)け**ておきます** - I will clean up my room before mum comes back
- 出(で)かける前(まえ)に、天気予報(てんきよほう)を調(しら)べて**おいて**ください。 - Please look up the weather forecast before leaving.
- 試験(しけん)の前(まえ)によく復習(ふくしゅう)して**おいて**ね。 - Please review well before the test.
- あのレストランはとても人気(にんき)ですから、予約(よやく)して**おかないと**入(はい)れません。と=if - Because that restaurant is very popular, if we don't make a reservation in advance, we can't enter.

## Notes

Often confused with てある — ておく is a deliberate action done *for* a future purpose, agent in focus (窓を開けておく - I'll leave the window open); てある describes the resulting state of someone's prior deliberate action, agent usually unstated (窓が開けてある - the window has been left open).

## Register

Register: tiered
Neutral baseline is ておきます; おいとく／しとく (dropping て before く) are casual, spoken-register contractions.

## Often confused with

- [Vて形 + あります - explain conditions/situations of an object - current or continuous states](/JapaneseNotes/grammar-index/grammar/vte-arimasu-resultant-state) — test: Is this a deliberate action done now for future benefit, agent in focus (→ ておく), or the resulting state from someone's prior deliberate action, agent usually unstated (→ てある)?
