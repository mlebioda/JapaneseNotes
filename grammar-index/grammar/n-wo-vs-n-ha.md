# N＋を　vs N＋は

> Marking a noun as a plain object with を versus topicalizing it with は.

## Structure

- rest of the sentence + N + を + V — neutral, N stated as a plain object
- N + は + rest of the sentence — N topicalized (は replaces を; they never stack)

## Examples

- もう荷物(にもつ)をじゅんびしました。 - I have packed my suitcase (neutral — baggage as plain object)
- 荷物(にもつ)はもうじゅんびしました。 - I have packed my suitcase (baggage as topic — e.g. contrasted with other things)
- 朝(あさ)ご飯(はん)は家(いえ)で食(た)べます。 - I eat breakfast at home (breakfast as topic — e.g. contrasted with other meals)
- 家(いえ)で朝(あさ)ご飯(はん)を食(た)べます。 - I eat breakfast at home (neutral — breakfast as plain object)
- お弁当(べんとう)はもう作(つく)りました。 - I have made a lunch box (lunch box as topic — e.g. contrasted with other things)
- もうお弁当(べんとう)を作(つく)りました。 - I have made a lunch box (neutral — lunch box as plain object)
- タバコはここで吸(す)ってもいいですか。 - Can I smoke cigarettes here? (cigarettes as topic — e.g. contrasted with other things, like alcohol)
- ここでタバコを吸(す)ってもいいですか。 - Can I smoke cigarettes here? (neutral — cigarettes as plain object)

## Use Cases

Use を when N is a plain object with no particular contrast intended. Use は to topicalize N and imply a contrast with other things — this is a topic-marking function, not a politeness distinction; register comes entirely from the verb ending, not from choosing は or を.

## Register
Register: neutral
Used identically in casual and polite speech — the choice between を and は is a topic-marking function, not a politeness distinction; register comes entirely from the verb ending.

## Often confused with

- [は - marks a phrase (already carrying another particle) as a contrastive topic](/JapaneseNotes/grammar-index/grammar/ha-contrastive-topic-marker) — test: Is は replacing a bare subject/object marker (が／を) entirely, or stacking onto a particle that marks place/time/direction (に／で／から／まで／へ)?
