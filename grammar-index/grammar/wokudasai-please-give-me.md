# をください - please give me

> Ask for something by name (and amount) — a standard everyday request.

## Structure

- N + を (amount) ください — please give me N
	- ぎゅうにゅうをください — please give me milk
	- 切手を２枚ください（きって）— please give me 2 stamps
- をお願いします — a softer alternative, often used when ordering (e.g. in a restaurant/cafe): コーヒーをお願いします — Coffee, please. Both are common; ください is a more direct request, お願いします is a bit softer/more service-oriented.

## Examples

- ぎゅうにゅうをください - please give me milk
- 切手を２枚ください（きって）- please give me 2 stamps
- A: これをください B: はいかしこまりました - A: Please give me this B: Yes sir/madam
- A:82円の切手をください B: 何枚ですか A: 一枚ください（えん、きって、なんまい）- A: Please give me 82 yen stamps B: How many do you want? A: One please

## Use Cases

ください is a standard polite request form for everyday transactions (asking a shop clerk, waitstaff, or a peer for something). It is not restricted by relative rank — if anything, for a genuine superior or a more deferential request, softer forms like 〜ていただけますか are preferred instead.

## Register

Register: polite-context typical

## Often confused with

- [お/ご V「ます形」ください - Respectful request form (尊敬語)](/JapaneseNotes/grammar-index/grammar/o-go-v-masukudasai-respectful-request-form) — test: Are you asking for a tangible object (N＋を＋ください), or respectfully asking the listener to perform an action (お/ご V「ます形」ください)?
