# Order

> The general tendency for ordering elements in a Japanese sentence: Time before Place before Object, with the verb last.

## Structure

Time + Place + Object + Verb — a common tendency, not a strict rule, since particles mark grammatical roles rather than sentence position. Time usually precedes Place, but a phrase marked as topic with は moves to the front regardless (e.g. 明日は図書館で勉強する).

## Examples

- 明日図書館で日本語を勉強する - tomorrow, I will study Japanese in the library

## Register

Register: neutral
A structural word-order tendency, not tied to formality — it applies equally in polite and plain speech, since the underlying rule (particles mark grammatical role, not position) holds regardless of register.
