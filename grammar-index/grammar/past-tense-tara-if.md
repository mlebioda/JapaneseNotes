# past tense + たら - if

> A conditional: if/when A happens, B (a possible or planned result).

## Structure

### Verb
- Affirmative: V「た」ら + B → しゅくだいができたら、私(わたし)に出(だ)してください - If you finish the homework, please submit it to me

### い-adjective
- Affirmative: Adj (drop い) + かったら + B → このパソコンはもっと安(やす)かったら、買(か)います - I would buy this computer if it is cheaper.

### な-adjective
- Affirmative: Adj + だったら + B → 暇(ひま)だったら、家(いえ)で一緒(いっしょ)にゲームをやろうか - If you're free, let's play a game together at my house.

Formation rule (all word types): A + V「た」ら／Adj-かったら／Adj-だったら／N-だったら + B

## Examples

- しゅくだいができたら、私(わたし)に出(だ)してください - If you finish the homework, please submit it to me
- 雨(あめ)が降(ふ)ったら、遊園地(ゆうえんち)に行(い)きません。- If it rains, we won't go to the amusement park.
- このパソコンはもっと安(やす)かったら、買(か)います。- I would buy this computer if it is cheaper.
- 暇(ひま)だったら、家(いえ)で一緒(いっしょ)にゲームをやろうか。- If you're free, let's play a game together at my house.

## Notes

Difference between たら and と:
- たら — A hasn't happened yet; B is one possible result once it does.
  - しゅくだいができたら、私に出してください - If you finish the homework, please submit it to me (cannot be said using と)
- と — A habitually/automatically causes B.
  - 左(ひだり)へ曲(まが)ると、病院(びょういん)が見(み)えます - If you turn left, you can see a hospital (can also be expressed using たら)
- Key test: と cannot be followed by a volitional, request, or command in clause B — that's why the homework example above must use たら (出してください is a request; しゅくだいができると、出してください would be ungrammatical).

## Register
Register: neutral
たら attaches to plain or ます-form clauses alike and carries no inherent politeness of its own — formality comes from the sentence-final form, not from たら itself.

## Often confused with

- [条件形（じょうけんけい）- ば - conditional form](/JapaneseNotes/grammar-index/grammar/joukenkei-ba-conditional-form) — test: Is the result a one-time/specific outcome (たら), or a general rule/formula that always holds (ば)?
- [。。。なら。。。- if](/JapaneseNotes/grammar-index/grammar/nara-if) — test: Does the condition happen before the result (たら), or is the speaker reacting to something already mentioned/known (なら)?
- [。。。場合は, 。。。 - in case of, if](/JapaneseNotes/grammar-index/grammar/baai-in-case-of-if) — test: Is this an everyday conditional (たら), or a more formal reference to a hypothetical case/scenario (場合は)?
- [V dict + と - if](/JapaneseNotes/grammar-index/grammar/v-dict-to-if) — test: Is the result a one-time possible outcome that can include a request/command (たら), or an automatic natural consequence that can never be volitional (と)?
