# used as a な adjective - essential/necessary

> Using 必要 as a な-adjective to describe something as necessary or unnecessary.

## Structure

### な-adjective
- Present (predicative): N + が + 必要（ひつよう） → お金(かね)が必要(ひつよう)です。 - Money is necessary.
- Attributive: 必要（ひつよう）な + N → 必要（ひつよう）な書類（しょるい） - necessary documents
- Negative (predicative): N + は + 必要（ひつよう）ではありません → この書類(しょるい)は必要(ひつよう)ではありません。 - This document isn't necessary.

## Examples

- お金(かね)が必要(ひつよう)です。 - Money is necessary.
- めがねが必要(ひつよう)になった。 - I came to need glasses. / Glasses became necessary.
- 新入生(しんにゅうせい)に必要(ひつよう)な書類(しょるい) - documents necessary for new students
- この書類(しょるい)は必要(ひつよう)ではありません。 - This document isn't necessary.

## Register

Register: neutral
必要 conjugates like a standard な-adjective; formality is carried by the surrounding copula (です／だ), not by 必要 itself.
