# まだ - still, not yet

> まだ + affirmative = "still"; まだ + negative = "not yet" — the mirror image of もう (already / anymore).

## Structure

- まだ + Affirmative (still / still as of yet / more besides) → 雪がまだ降っています。 - It is still snowing.
- まだ + Negative (not yet) → まだ食べていません。 - I haven't eaten yet.
- まだ + い-adjective (still, describing a state) → まだ早いです。 - It is still early.
- まだです — copula-only "not yet" with no verb → A: ご飯を食べましたか。B: いいえ、まだです。 - A: Have you eaten yet? B: Not yet.

## Examples

- 雪(ゆき)がまだ降(ふ)っています。 - It is still snowing.
- ９月(くがつ)に海外旅行(かいがいりょこう)に行(い)きます。今(いま)はまだ３月(さんがつ)です。 - I will travel overseas in September. It is still March now.
- 冷蔵庫(れいぞうこ)の中(なか)にリンゴがまだ５つあります。 - There are 5 more apples in the refrigerator.
- まだ食(た)べていません。 - I haven't eaten yet.
- 映画(えいが)はまだ終(お)わっていません。 - The movie is not over yet.
- 彼(かれ)はまだ寝(ね)ています。 - He is still sleeping.
- まだ早(はや)いです。 - It is still early.
- 私(わたし)はおみやげをまだ買(か)っていません。 - I haven't bought a souvenir yet.
- ラジさんはまだ荷物(にもつ)を準備(じゅんび)しています。 - Raj is still preparing the baggage.
- 週末(しゅうまつ)まで、まだ二日間(ふつかかん)あります。 - There are 2 more days until the weekend.
- A: ご飯(はん)を食(た)べましたか。B: いいえ、まだです。 - A: Have you eaten yet? B: Not yet.

## Use Cases

まだ is commonly taught opposite もう — もう + affirmative = "already," もう + negative = "not anymore," while まだ + affirmative = "still," まだ + negative = "not yet." まだ + affirmative covers four related nuances: still (雪がまだ降っています - It is still snowing), still/as of yet (今はまだ３月です - It is still March now), more besides (リンゴがまだ５つあります - There are 5 more apples), and describing a state via an い-adjective (まだ早いです - It is still early). まだです alone (no verb) answers "not yet" to a question.

## Register

Register: neutral
まだ is a register-neutral adverb; formality comes from the verb/copula it modifies, not from まだ itself.
