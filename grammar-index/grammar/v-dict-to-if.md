# V dict + と - if

> Expresses a natural or inevitable consequence — "if/when Condition, then Result."

## Structure

### Verb

- Present: V「dict」＋ と ＋ Result → 風邪を引くと、何もやりたくない。(かぜ・ひ・なに) - If I catch a cold, I don't want to do anything.
- Negative: V「nai」＋ と ＋ Result → この申込書(もうしこみしょ)がないと、申(もう)し込(こ)むことができません。 - If you don't have this application form, you cannot apply for it.

## Examples

- 風邪(かぜ)を引(ひ)くと、何(なに)もやりたくない。 - If I catch a cold, I don't want to do anything.
- 全部(ぜんぶ)の本(ほん)を入(い)れると、箱(はこ)は重(おも)すぎると思(おも)います。 - I think the box will be too heavy if I put all the books in it.
- この申込書(もうしこみしょ)がないと、申(もう)し込(こ)むことができません。 - If you don't have this application form, you cannot apply for it.

## Use Cases

The result clause can NEVER be a volition, request, command, or suggestion (can't say 春になると、旅行しましょう - "when it becomes spring, let's travel"). と is only for natural/inevitable consequences, discoveries, or automatic sequences — all example sentences above are statements, not commands, which is why と works for them.

## Register

Register: neutral
と works in both casual and polite speech; formality is carried by the surrounding verb form, not by と itself.

## Often confused with

- [条件形（じょうけんけい）- ば - conditional form](/JapaneseNotes/grammar-index/grammar/joukenkei-ba-conditional-form) — test: Can the result be a hypothetical wish/request (ば), or must it be an automatic, non-volitional natural consequence (と)?
- [past tense + たら - if](/JapaneseNotes/grammar-index/grammar/past-tense-tara-if) — test: Is the result a one-time possible outcome that can include a request/command (たら), or an automatic natural consequence that can never be volitional (と)?
- [。。。なら。。。- if](/JapaneseNotes/grammar-index/grammar/nara-if) — test: Is the speaker reacting to an already-stated/assumed plan with advice or suggestion (なら), or stating an automatic natural consequence (と)?
- [V dict とすぐです - As soon as ....](/JapaneseNotes/grammar-index/grammar/v-dict-tosugudesu-as-soon-as) — test: Is the result just a general natural consequence, any kind (plain と), or specifically that it happens immediately/right away (と + すぐです)?
