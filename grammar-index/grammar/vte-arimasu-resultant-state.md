# Vて形 + あります - explain conditions/situations of an object - current or continuous states

> Describes the current or continuous state/condition of an object, resulting from someone's deliberate action.

## Structure

- Transitive-Vて形 + あります - explain conditions/situations of an object
  - verb must be TRANSITIVE
  - only for object (subject is a thing, not a person)
  - the object of the original transitive verb is marked with が, not を - e.g. 本を置く -> 本が置いてある
  - Exception: with abstract "advance preparation" actions (申し込む, 予約する, 準備する), を is often kept instead of switching to が - the nuance shifts closer to Vておく ("do in advance for later benefit"), see 旅行を申し込んであります below
  - current or continuous state, wynik swiadomego czyjegos dzialania
  - focus on effect, not person

## Examples

- 机の上に本が置いてあります。(つくえ・うえ・ほん・お) - There is a book **left** on the desk. (someone put it)
- 燃えるごみはもう出してあります。(も・だ) - The burnable waste has already **been taken** out. (by someone)
- 旅行を申し込んであります。(りょこう・もう・こ) - I have already **applied** for traveling.

## Notes

Often confused with: Vている (intransitive resulting/ongoing state, no implied agent, e.g. 窓が開いています vs 窓が開けてあります)

## Register
Register: neutral
Used identically in speech and writing; describing a resultant state carries no inherent politeness dimension.

## Often confused with
- [V「て形」＋おきます - V continues without any changes, leave](/JapaneseNotes/grammar-index/grammar/v-te-okimasu) — test: Is this describing the resulting state from someone's prior deliberate action, agent usually unstated (→ てある), or a deliberate action done now for future benefit, agent in focus (→ ておく)?
