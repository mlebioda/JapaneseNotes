# N + は/が + V 「passive form」- passing information

> An agentless passive used to state a fact or event as noteworthy, without naming (or needing) who performed the action.

## Structure

- N + は/が + V「passive form」
    - Use cases
        - express facts considered noteworthy or important
            - この寺(てら)は江戸時代(えどじだい)に建(た)てられました。 - The temple was built in the Edo Period.
        - used when the agent is unknown, irrelevant, or an unspecified/general group
            - この小説（しょうせつ）は世界中（せかいじゅう）で読まれています（よ） - This novel is read all over the world

## Examples

- この小説（しょうせつ）**は**世界中（せかいじゅう）で読ま**れています**（よ） - This novel is read all over the world
- この寺(てら)は江戸時代(えどじだい)に建(た)てられました。 - The temple was built in the Edo Period.
- この絵(え)は17世紀(せいき)に描(か)かれました。 - This picture was drawn in the 17th century.
- 電報(でんぽう)はいつ発明(はつめい)されたの？ - When was the telegram invented?

## Use Cases

**Aspect matters here:** 読まれています (passive + ている) marks an ongoing/general state ("is read [habitually, right now]"), while 建てられました／描かれました (passive + た) mark a one-time completed historical event ("was built/drawn"). Same passive form, different aspect layered on top.

This agentless "informational passive" is typical of formal/written Japanese — news reports, history, reference text. It reads more neutral/objective than the suffering-passive uses above, which carry a personal, often negative, emotional charge.

## Register
Register: polite-context typical
Typical of formal or written Japanese — news reports, historical accounts, reference texts — where the agent doesn't matter and a neutral, objective tone is wanted. Less common in casual spoken narration, which tends to prefer active voice or naming the agent directly.
