# 枚　まい - counter for flat/thin objects

> Counter for flat, thin objects — paper, tickets, plates, shirts, CDs, etc.

## Structure

Number + 枚（まい）

| Number | Reading | Meaning |
|---|---|---|
| 一枚 | いちまい | 1 flat object |
| 二枚 | にまい | 2 flat objects |
| 三枚 | さんまい | 3 flat objects |
| 四枚 | よんまい | 4 flat objects |
| 五枚 | ごまい | 5 flat objects |
| 六枚 | ろくまい | 6 flat objects |
| 七枚 | ななまい | 7 flat objects |
| 八枚 | はちまい | 8 flat objects |
| 九枚 | きゅうまい | 9 flat objects |
| 十枚 | じゅうまい | 10 flat objects |
| 何枚 | なんまい | how many flat objects? |

## Examples

## Use Cases

Register-neutral — used the same way in casual and polite speech.

## Register
Register: neutral
Counters attach the same way regardless of formality — used identically in casual conversation and polite/formal speech.
