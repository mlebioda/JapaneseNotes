# 条件形（じょうけんけい）- ば - conditional form

> Expresses a hypothetical or general condition — "if A, then B" — formed by conjugating the verb/adjective/noun into its ば-ending; the most formal/literary of the four Japanese conditionals.

## Structure

**Formation:** A ば、B — "If A, then B"

### Verb

**Group 1 (U-verbs):** change the final う-sound to the え-row + ば

| Plain | ば form |
| ----- | ------ |
| 書く    | 書けば    |
| 飲む    | 飲めば    |
| 話す    | 話せば    |
| 待つ    | 待てば    |
| 乗る    | 乗れば    |

**Group 2 (RU-verbs):** drop る → add れば

| Plain | ば form |
|-------|---------|
| 食べる | 食べれば |
| 見る | 見れば |

**Group 3 (irregular):**

| Plain | ば form |
|-------|---------|
| する | すれば |
| くる | くれば |

**Negative:** ない → なければ
- 食べない → 食べなければ
- しない → しなければ

### い-adjective

Drop い → add ければ

| Plain | ば form |
|-------|---------|
| 高い | 高ければ |
| 安い | 安ければ |
| いい | よければ |

### な-adjective

Add であれば (or なら（ば - often omitted） in casual speech)

| Plain | ば form - formal written | natural, spoken |
| ----- | ----------------------- | --------------- |
| 大切    | 大切であれば                  | 大切なら（ば）         |

### Noun

Add であれば (or なら（ば - often omitted） in casual speech). でしたら is also common as a polite/formal noun conditional, especially in customer-service Japanese.

| Plain | ば form - formal written | natural, spoken | polite |
| ----- | ----------------------- | --------------- | ------ |
| 学生    | 学生であれば                  | 学生なら（ば）         | 学生でしたら |
| 日本人   | 日本人であれば                 | 日本人なら（ば）        | 日本人でしたら |

## Examples

- このボタンを押(お)せば、ドアが開(ひら)きます。 - If you press this button, the door will open.
- このケーキがおいしければ、また買(か)いに行(い)きます。 - If this cake is delicious, I will go to buy it again.
- 非常(ひじょう)に不便(ふべん)じゃなければ、引越(ひっこ)しする必要(ひつよう)がありません。 - If it's not extremely inconvenient, there's no need to move.
- 明日(あした)天気(てんき)がよければ、一緒(いっしょ)に散歩(さんぽ)に行(い)きましょう。 - If the weather is nice tomorrow, let's go for a walk together.

## Notes

**When ば is awkward:** ば is awkward when clause B is a deliberate, same-subject volitional action — たら is preferred there:
- ❌ 家(いえ)に帰(かえ)ればテレビを見(み)ます。
- ✅ 家(いえ)に帰(かえ)ったらテレビを見(み)ます。 - When I get home, I'll watch TV.

ば works fine with wishes/requests/volitional B when the subjects of A and B differ, or in set expressions:
- ✅ 明日(あした)天気(てんき)がよければ、一緒(いっしょ)に散歩(さんぽ)に行(い)きましょう。（A's subject: 天気 / B's subject: we）
- ✅ よければ、一緒(いっしょ)に行(い)きませんか。 - If you'd like, would you come with me?

**ば vs たら vs と vs なら — comparison:**

|                         | ば                          | たら                                    | と                                              | なら                                             |
| ----------------------- | -------------------------- | ------------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| **Formation**           | う→えば / ければ / であれば          | た form → たら                           | dictionary form + と                            | plain form + なら (no conjugation)               |
| **Focus**               | condition (hypothetical)   | when / after / if (sequential)        | natural consequence / always true              | reacts to assumed / stated intention           |
| **Result**              | can be hypothetical        | result always follows after condition | result *always* follows automatically          | advice / suggestion based on what A plans      |
| **Speaker's will in B** | ✅ can express wish/request | ✅ can express wish/request            | ❌ B must be objective fact, not speaker's will | ✅ very common with suggestions                 |
| **Past events**         | ❌                          | ✅ (たら can express discovery: したら〜だった) | ❌                                              | ❌                                              |
| **Nuance**              | logical / formal           | most versatile, everyday use          | automatic / inevitable                         | "since you're going to" / "if that's the case" |

**Examples with the same meaning:**

| ば                               | たら                                | と                                        |
| ------------------------------- | --------------------------------- | ---------------------------------------- |
| 春になれば、花が咲く。                     | 春になったら、花が咲く。                      | 春になると、花が咲く。                              |
| If spring comes, flowers bloom. | When spring comes, flowers bloom. | When spring comes, flowers always bloom. |

**When they are NOT interchangeable:**

**と — cannot use when B is speaker's will/desire/request:**
- ❌ 駅に着くと、電話してください。
- ✅ 駅に着いたら、電話してください。 — When you arrive at the station, please call.

**たら — discovery (past):**
- 家に帰ったら、誰もいなかった。— When I got home, nobody was there. (ば/と cannot replace this)

**ば — more formal/hypothetical, common in set expressions:**
- よければ — if you'd like
- 行けば良かった — I should have gone

## Register

Register: neutral
Used across all social registers — ば itself doesn't mark politeness toward a listener; that comes from the surrounding copula/verb form. However, it carries a literary/formal flavor compared to たら, and is especially common in written Japanese, proverbs, and fixed expressions (よければ, 〜ば〜のに); in casual spoken conversation, たら is often preferred for the same meaning.

## Often confused with

- [。。。なら。。。- if](/JapaneseNotes/grammar-index/grammar/nara-if) — test: does B react to an already-stated/assumed plan (なら) or express a general hypothetical/logical condition (ば)?
- [。。。場合は, 。。。 - in case of, if](/JapaneseNotes/grammar-index/grammar/baai-in-case-of-if) — test: is this a general hypothetical "if A then B" (ば) or a specific contingency/scenario instruction "in the case that A happens" (場合は)?
- [past tense + たら - if](/JapaneseNotes/grammar-index/grammar/past-tense-tara-if) — test: Is the result a one-time/specific outcome (たら), or a general rule/formula that always holds (ば)?
