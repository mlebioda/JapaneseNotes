# これ/それ/あれ/どれ

> Ko-so-a-do demonstrative pronouns that stand alone to refer to things by proximity, without a following noun.

## Structure

これ / それ / あれ / どれ (standalone — no noun follows)

## Meaning

Demonstrative pronouns used without a noun:
- これ — this one (near speaker)
- それ — that one (near listener)
- あれ — that one (far from both)
- どれ — which one?

Contrast with この/その/あの/どの which always precede a noun.

## Examples

- これは何ですか - What is this?
- それはペンです - That is a pen.
- あれは山です - That over there is a mountain.
- どれですか - Which one is it?
