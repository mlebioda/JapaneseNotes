# 頼む（たの）- to ask(for help)/entrust

## 1. Ask for help

### Structure

Verb, u-verb (group 1). N + に + 頼む — to ask N for help.

### Examples

- 父に頼む（ちち、たの）- to ask father (for help)
- 友達に頼む（ともだち、たの）- to ask a friend (for help)

## 2. Entrust something to someone

### Structure

N1 + に + N2 + を + 頼む — to entrust N2 to N1.

### Examples

- 仕事を頼む（たの）- to entrust someone with work (powierzyć komuś pracę)
- コピーを頼む（たの）- to ask someone to make a copy
- 山田さんに私の仕事を頼みます（たの）- I'll ask Yamada to do my work for me
