# 返す（かえす）- to return

## Structure

返す (godan, transitive) — "to return (something)" to someone. N1 に N2 を 返す.

## Examples

- 本を返す（かえ）- to return a book
- 傘を返す(かさ、かえ) - to return an umbrella
- 図書館に本を返します（図書館、かえ）- I will return the book to the library
- 山田さんにDVDを返しました（かえ）- I returned the DVD to Yamada
