# I think - と思います

## Structure

と思います — "I think that ~". と思う is the plain/casual equivalent; と思います the polite/ます register — same sentence, different formality level.
- Attaches to: Vdict/た-form + と思います / いadj + と思います / なadj + だ + と思います / N + だ + と思います
- Limited to first person — states only the speaker's own immediate assertion. To describe a third person's ongoing belief, use と思っている instead, e.g. 田中さんは正しいと思っています - Tanaka thinks it's correct.
- Question: どう思いますか・どう思う — what do you think?
- Negative: negate the embedded clause (ないform + と思います) rather than 思う itself — negating と思う with と思いません sounds more blunt/assertive.

## Examples

- このビールは美味しいと思います（おいしい、おも）- I think this beer is delicious
- 明日雨が降ると思います（ふ）- I think it will rain tomorrow
- A: 新しい家は どう思いますか B: 広いですが、ちょっと交通が 不便だと思います（あたら、いえ、おも、ひろ、こうつう、ふべん）- A: How is your new house? B: It's big, but access to transportation is inconvenient
- どう思いますか・どう思う - what do you think? (polite/casual)
- この白い服はどう思う？ B:いいと思う（ふく）- what do you think about this white dress(clothes)? B: I think it's good
- ワンさんは まだ 寝ていない と思います（ね、おも）- I think Miss Wang is not sleeping
- 明日 風が 強くないと思います（かぜ、つよ） - I don't think the wind will be strong tomorrow
- これは 私の 資料じゃないと思います（しりょう）- I don't think this is my material
