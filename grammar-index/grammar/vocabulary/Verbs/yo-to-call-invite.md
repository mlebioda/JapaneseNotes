# 呼ぶ（よ）- to call, invite

## 1. Call someone / call out a name

### Structure

Verb, u-verb (group 1). N + を + 呼ぶ.

### Examples

- わんさんを呼んでいます（よ）- I'm calling Miss Wang (przywołać)
- アンドさんはお兄さんを呼んでいます（にい、よ）- Miss Ando is calling (woła) her elder brother

## 2. Invite someone to an event

### Structure

N（person） + を + P（place） + に + 呼ぶ.

### Examples

- 先生をパーティーに呼びましょう（よ）- let's invite the teacher to the party

## 3. Call someone to come forward

### Structure

N + を + 呼ぶ.

### Examples

- タクシーを呼ぶ（よ）- to hail a cab
- 医者を呼ぶ（いしゃ、よ）- to call the doctor
