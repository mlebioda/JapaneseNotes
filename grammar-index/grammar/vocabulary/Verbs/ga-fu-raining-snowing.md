# が＋降る（ふ）- raining/snowing

## Structure

降る (ふる) — godan intransitive verb, "to fall" (used for rain/snow).
- Collocation: X が降る (雨が降る - it rains; 雪が降る - it snows)
- Commonly appears in て形＋いる (降っています) to describe weather happening right now, in contrast to the plain form + でしょう used elsewhere in this lesson for forecasting (e.g. 明日は雨でしょう).

## Examples

- 雨(あめ)が降(ふ)っています。 - It is raining.
