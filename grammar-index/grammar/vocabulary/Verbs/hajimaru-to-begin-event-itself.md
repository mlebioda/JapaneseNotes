# 始まる (はじまる) - to begin (event, itself)

## Structure

Intransitive — …が + 始まる: happens by itself, no one causes it. Transitive counterpart: 始める (to start something), which takes を instead of が — e.g. 私が映画を始める ("I start the movie") vs 映画が始まる ("the movie starts by itself").

## Examples

- 映画(えいが)が始(はじ)まる。 - The movie begins.
- 春(はる)が始(はじ)まる。 - Spring begins.
