# 同じ - same

## Structure

な-adjective, reading おなじ. Special な-adjective that drops な before a noun — 同じ人, never 同じな人, unlike regular な-adjectives (きれいな人). Also used predicatively (これは同じです) and adverbially (同じように - "in the same way, similarly").

## Examples

- 同じ会社（おなじかいしゃ) - same company
- 同じ大学（おなじだいがく) - same university
- これは同じです（おなじ）- this is the same
- 同じように（おなじように）- in the same way, similarly
