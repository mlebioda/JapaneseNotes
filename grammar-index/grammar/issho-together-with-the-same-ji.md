# いっしょ  - together, with, the same (同じ

> いっしょ expresses either doing something together (with に) or that two things are the same (with と).

## Structure

- いっしょ + に + Verb → together (shared action)
- N + と + いっしょ → the same as N

## Examples

- いっしょにいきましょう — Let's go together.
- 私の学校は弟の学校といっしょです — My school and my younger brother's school are the same.
