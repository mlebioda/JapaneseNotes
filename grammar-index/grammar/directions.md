# Directions

> Basic direction words, and the 側（がわ）suffix meaning "the ... side".

## Structure

Direction word + 側（がわ）

| Word | Reading | Meaning |
|---|---|---|
| 右 | みぎ | right |
| 左 | ひだり | left |
| 前 | まえ | front |
| 後ろ | うしろ | back |
| 右側 | みぎがわ | right side |
| 左側 | ひだりがわ | left side |
| 前側 | まえがわ | front side |
| 後ろ側 | うしろがわ | back side |

## Examples

- 銀行(ぎんこう)の後ろ側(うしろがわ)に映画館(えいがかん)があります - There is a cinema behind the bank.

## Register
Register: neutral
右／左／前／後ろ and the 側 suffix are register-neutral vocabulary, used the same way in casual and polite speech.
