# Fill-templates: Kanji trainer link scope fix

## Goal
Kanji trainer links for `#wc` and `#wp` cards are currently generated by scanning the entire completed template text, including conjugation-form header names (ます形, 可能形, 出す形, 尊敬語, etc.). This produces spurious links for kanji that belong to those header labels rather than to the word being studied. The fix narrows the source text for `#wc`/`#wp` cards to the `ほんやく:` value only, then removes already-generated bad links from Kaligrafia-1 through Kaligrafia-5.

## Approach
Two independent edits. Part 1 is a single rule-text change in `fill-templates.md`. Part 2 is a Python script that parses each Kaligrafia file, identifies `#wc`/`#wp` card blocks, derives the correct kanji set from the `ほんやく:` line, and replaces the existing `<a …>` link lines with the corrected set.

## Steps

### Part 1 — fix the skill rule

**File:** `.cowork/skills/fill-templates.md`

**Section:** `## Kanji trainer links` → `### Procedure (per template)`

**Old text (exact):**
```
1. Collect every character in the completed template text (all lines including ほんやく, forms, etc.).
```

**New text:**
```
1. Determine the source text for kanji collection:
   - For `#wc` and `#wp`: use ONLY the value of the `ほんやく:` line (strip the `ほんやく:` prefix, then strip any furigana in 〇（〇）or 〇(〇) notation — collect kanji from the bare Japanese word/expression only).
   - For `#w`: use the Japanese field line only (unchanged from previous behaviour).
```

This change affects step 6 (verb/adjective cards) and step 8 (`#w` cards) of the main workflow — the other steps are unaffected.

### Part 2 — cleanup script for Kaligrafia-1 through Kaligrafia-5

**Target files:**
- `JPLessons/Udemy/N4/Kaligrafia/Kaligrafia-1-Company.md`
- `JPLessons/Udemy/N4/Kaligrafia/Kaligrafia-2-Study.md`
- `JPLessons/Udemy/N4/Kaligrafia/Kaligrafia-3-Family.md`
- `JPLessons/Udemy/N4/Kaligrafia/Kaligrafia-4-Meal.md`
- `JPLessons/Udemy/N4/Kaligrafia/Kaligrafia-5-Shopping.md`

**Script location:** `Plans/fix_kanji_links.py`

**Script logic:**
1. Read each target file.
2. Locate the `# Summary` separator line; process only content below it.
3. Scan below `# Summary` for `#wc` and `#wp` card blocks. A block starts at a `#card` line and ends at the next blank separator line (`---`) or the next `#card` line.
4. Within each `#wc`/`#wp` block:
   a. Find the `ほんやく:` line and extract its value.
   b. Strip the `ほんやく:` prefix.
   c. Strip furigana: remove everything matching `（[^）]*）` and `\([^\)]*\)`.
   d. Collect unique CJK characters (U+4E00–U+9FFF) in left-to-right order from the remaining string.
   e. Rebuild the correct `<a>` link lines from that set.
   f. Replace all existing consecutive `<a href="https://kanji-trainer.org/…">…</a>` lines in the block with the rebuilt set.
5. Write the file back only if any change was made.
