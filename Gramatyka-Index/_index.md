# Grammar Index

This folder is a topic-grouped reference index built incrementally by the `summarize-grammar` skill. Each topic file lists wikilinks to source lesson sections — no lesson text is copied.

Run `summarize-grammar <lesson>` (e.g., `summarize UN4GL5`) after creating a new lesson to add its grammar points to the relevant topic files. A grammar point may appear in multiple topics.
